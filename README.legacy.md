## 💼 Featured Projects

### 1. Campus Cable Planner
* **Description:** A C-based campus cable planning system developed to design, organize, and manage network connections between different buildings or locations within a campus. The system uses graph-based algorithms and data structures to determine efficient cable connections and minimize overall cable cost.
* **Tech Stack:** C, Data Structures, Graph, Minimum Spanning Tree (MST), Prim's Algorithm, Dijkstra Algorithm
* **GitHub Repository:** [Campus Cable Planner](https://github.com/Sabbir086/Campus-Cable-Planner)

### 2. Land Management System
* **Description:** A C-based land management system developed to organize land records, calculate land taxes, and keep track of land-related transactions using linked lists, stacks, and queues.
* **Tech Stack:** C, Data Structures, Linked List, Stack, Queue
